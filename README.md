# Tree Lang

基于 C++ 开发的传统地牢 MUD 游戏。

## 一、 概述与目标

传统 MUD 地牢玩法，玩家需在 $5 \times 5$ 随机连通的地图中逐层深入，挑战愈发强大的敌人，并根据抉择走向多元结局。战斗强调属性克制与连击节奏，成长依赖资源管理与构筑搭配。

## 二、 核心机制：战斗系统

### 1. 术式（技能）基础

游戏内的技能统称为 **【术式】**。每个术式由以下参数定义：

- **冷却回合**：使用后需要等待的回合数。
- **元素属性列表**：一个术式可承载 1 至多条元素属性（如火、水、金等），每条属性附带独立的 **属性等级**。
- **基础伤害倍率**：该术式造成的伤害系数。

> **伤害结算逻辑**：术式命中时，其携带的所有元素属性分别对敌人计算伤害，但最终仅 **取最大值** 作为本次攻击的最终伤害。属性等级与伤害呈 **一次函数关系**（即 $伤害 = 基础伤害 \times 等级系数$）。

### 2. 元素克制与“黑闪”（暴击）

当术式中某条元素属性 **克制** 当前敌人的弱点属性时，该次攻击触发 **【黑闪】**。

- **黑闪效果**：该次伤害基础倍率提升至 **$120\%$**。
- **备注**：黑闪是进入“心流”状态的唯一钥匙，也是重置连击层数的触发器。

### 3. 心流状态（连击机制）

- **进入条件**：任意术式触发“黑闪”后，**下一回合** 玩家自动获得【心流】状态。
- **状态效果**：心流状态下，每成功延续一回合，伤害倍率呈阶梯式增长。若持续至第 $n$ 回合，当回合最终伤害为：
  $$ \text{最终伤害} = \text{基础伤害} \times \prod_{k=1}^{i} (1+0.2i) $$
  即 Round 1: ×1.2；Round 2: ×1.2×1.4；Round 3: ×1.2×1.4×1.6……

#### 【属性传递链（延续规则）】

维持心流不中断需要遵循 **“承上启下”** 原则：

- **激活属性**：本回合中，用于触发敌人弱点的元素属性（即造成黑闪的那一条）。
- **传导属性（钥匙）**：术式列表中，**除激活属性之外**的其他所有元素属性。
- **延续判定**：若当前回合术式的 **传导属性**，与上一回合维持心流的术式的 **传导属性** 存在**任意交集**，则心流延续。
- **钥匙更新**：成功延续后，**上一回合的钥匙失效**，替换为本回合术式的新传导属性作为下一回合的钥匙。

#### 【心流中的再暴击（层数重置）】

若在心流状态下，当前术式再次触发了“黑闪”：

- 伤害递增层数 **立即清零**（下一回合伤害从 ×1.2 重新开始计算）。
- 但 **心流状态不会中断**，传导属性（钥匙）按当前术式正常更新。

### 4. 术式熔断（冷却惩罚）

当 **心流状态因传导属性不匹配而中断** 时，触发【术式熔断】：

- **惩罚对象**：所有参与过本轮心流链路的术式（**包含**触发首轮黑闪的术式）。
- **惩罚数值**：增加 `心流持续回合数 - 1` 回合的额外冷却时间（等同于 `参与连击的术式数量 - 1`）。
- **举例**：若连击了 3 个术式后断连，这 3 个术式全部增加 2 回合冷却。

### 5. 术式融合（强化）

在特定房间内，可将两个术式进行 **融合强化**。

- **消耗**：根据融合双方属性等级高低，消耗不同数量的金币。
- **效果**：将双方的属性列表 **合并累加**。若存在同名属性，则 **等级直接相加**。
  > 示例：术式A（火+1） + 术式B（火+2, 水+1） = 新术式（火+3, 水+1）。

### 6. 道具系统

**[待补充]** 拟包含消耗品（回血/回蓝）、战术道具（赋予临时属性）等。

## 三、 地图与房间机制

玩家每次进入新一层时，出现在 $5 \times 5$ 网格的 **正中央房间**，该房间视为安全的【初始补给点】。

房间类型包含（但不仅限于）：

1. **初始房（中央）**：提供简易商店，可购买基础恢复品。
2. **奖励房**：战斗胜利后出现，提供随机新术式或强化素材。
3. **功能房**：提供【术式融合】服务。
4. **精英怪房**：守卫关键通路，击败后提供高品质奖励。
5. **剧情房**：触发 NPC 对话或特殊事件。

### 玩家系统——状态

## 四、 玩家状态系统

### 1. 咒力（法力）

释放术式需要消耗咒力，咒力在战斗与非战斗回合中 **缓慢恢复**。

- **复杂术式消耗**：术式承载的属性条数越多，消耗呈 **指数增长**。
- **心流连击消耗**：在心流状态下，咒力消耗与连击次数呈 **一次函数关系**。

### 2. 血量（生命值）—— 唯一败北条件

- 当血量归零时，游戏 **立即结束**，进入结局阶段（死亡结局）。
- 血量 **不会** 随时间自动恢复，只能通过事件、道具或特定术式恢复。
- 受到伤害时，护盾优先抵消，剩余伤害直接扣除血量。

### 3. 理智（SAN）

理智值范围 $[0, 100]$，影响叙事、交互与战斗表现，但 **理智归零不会导致游戏结束**。

- **扣除来源**：每次通过楼层固定扣除；受到血量伤害时额外扣除（扣除量受 **损失血量** 与 **敌我理智差值** 影响）。
- **交互影响**：玩家与 NPC 交谈时，**理智高的一方会向低的一方转移少量理智**（即高者降低，低者升高）。
- **理智归零后果**：玩家进入 **“失控”** 状态，无法使用复杂术式，且商店价格飙升，直到通过特定道具或事件恢复至 1 点以上。
- **NPC 成功率**：若玩家理智低于 NPC，交谈成功率下降；反之则上升。

### 4. 护盾

- 护盾值与血量 **1:1** 抵消伤害（有特殊说明时除外，如真实伤害）。
- 非战斗状态下，护盾会 **缓慢自然恢复**。

## 五、 玩家属性系统（S.P.E.C.I.A.L.）

玩家拥有 7 项基础属性，随等级提升获得 **属性点** 进行分配，**每项属性上限为 20 点**。

| 属性     | 英文         | 核心作用                                   |
| :------- | :----------- | :----------------------------------------- |
| **力量** | Strength     | 决定基础攻击力加成。                       |
| **感知** | Perception   | 决定能否查看敌人的具体数值（血量、弱点）。 |
| **耐力** | Endurance    | 决定护盾上限与恢复速度。                   |
| **魅力** | Charisma     | 决定对话成功率与商店折扣比例。             |
| **智力** | Intelligence | 决定 SAN 值上限与 SAN 恢复效率。           |
| **敏捷** | Agility      | 决定对话失败时的闪避率与战斗逃跑成功率。   |
| **运气** | Luck         | 影响奖励品质与随机事件倾向。               |

## 六、 成就与永久奖励系统

玩家在达成特定条件（如首次击杀 Boss、完成特定连击数）时解锁成就。

- **奖励性质**：**永久性**，全存档通用。
- **奖励类型**：
  - 额外可执行行动（如开局额外抽牌/术式）。
  - 特殊称号（影响属性系统）。
  - 装扮/特效（视觉表现层）。
