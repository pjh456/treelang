## Repository Map

Codemaps live under `doc/codemap/`. The master atlas is `doc/codemap/atlas.md`.

Before working on any task, read `doc/codemap/atlas.md` to understand:
- Project architecture and entry points
- Directory responsibilities and design patterns
- Data flow and integration points between modules

Per-folder maps: `doc/codemap/src.md`, `doc/codemap/tests.md`.

Do not add files to the repo root or source trees for documentation purposes —
keep docs under `doc/`.
